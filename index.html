Web Technology

Discover the technologies that power the modern web.

HTML - Structure

HTML stands for HyperText Markup Language. It provides the basic structure of a webpage using elements such as headings, paragraphs, images, links, and divisions.

CSS - Styling

CSS stands for Cascading Style Sheets. It controls the appearance of webpages through colours, fonts, spacing, layouts, animations, and responsive design.

JavaScript - Interaction

JavaScript makes webpages interactive. It can respond to user actions, validate forms, update content dynamically, and create engaging web applications.
